占格规则（本次改动）

  • 小件 1x1（28 件）：小型瞄具、小握把、民用小弹匣、折叠托、消焰器 —— 口袋也能塞。
  • 中件 2x1（35 件）：消音器 / 制退器 / 常规瞄具 / 扩容弹匣 / 战术托 / 电磁制退环 —— 横放在 2 列以上的舱里。
  • 长件 3x1（18 件）：加长枪管 / 连发枪管 / 倍镜 / 抑制器 / 两脚架 / 机械稳定爪 / 弹链转换器 / 供弹手稳定托 —— 3x1 是弹挂最主流的舱形（blocks 里 [3,1] 遍地都是），横着正好卡进一格；进不去就自动躺倒成 1x3，竖舱也吃得下。
  • 弹鼓 2x2（3 件）：哈夫克快拔弹鼓 / 轻量化弹鼓 / 野战弹鼓 —— 又粗又圆，全表只剩它占 4 格。
  • 口袋是 5 个独立的单格舱，所以 2 格以上的配件塞不进裤兜，搜到长件必须往弹挂 / 背包里放。
