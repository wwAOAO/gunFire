# NEON PURGE · 霓虹搜打撤

2D 俯视角「搜打撤」（Extraction Shooter）小游戏。你是一名进入阿萨拉坝区「零号大坝」的干员：翻箱倒柜搜物资、和驻守部队交火、然后活着走到撤离点。

纯前端单文件实现，**零依赖、零构建、双击即玩**（推荐 Chrome / Edge）。

---

## 快速开始

```bash
# 方式一：直接双击（无需任何环境）
index.html          # 游戏
editor.html         # 地图编辑器

# 方式二：本地起个静态服务（可选，便于同源共享浏览器存储）
python -m http.server 8080
# 然后访问 http://localhost:8080/index.html
```

仓库是纯静态资源，也可以直接在 GitHub 仓库的 Settings → Pages 里把 `main` 分支根目录发布成在线试玩页。

## 玩法循环

1. **大厅整备**：挑主武器、护甲、补给（医疗包 / 弹药包），再去「弹药」页按口径买弹、选弹级，最后选一张作战地图。
2. **出击**：进入封锁区，视野只有正面一片扇形，身后与掩体背面永远是雾；靠近容器按 `F` 搜刮，物品一件件翻出来。
3. **交战**：开枪会暴露位置，一个敌人发现你就会喊来周围所有人。被打死等于全部携带装备和包里收集品蒸发。
4. **撤离**：走到绿色撤离点站住 6 秒完成撤离，箱子里的东西才算真正到手。
5. **结算**：收集品先进仓库，**卖掉才变成资金**；资金用来买枪、护甲、弹药、补给。

**只有匕首永久保底**：新档一把枪都没有，G17 也要花 ¥700 去军火库买（或去局内缴获）。**子弹也要买**，而且打出去的、装进弹匣带进图的都算花掉了 —— 撤离不返还，阵亡也不返还。破产了可以先空手带刀出击，摸到枪再翻身。

## 两张图 · 两种难度

内置地图有且只有一张地形（零号大坝），但给了两套数值：

| | 零号大坝·普通 | 零号大坝·机密 |
| --- | --- | --- |
| 定位 | 熟悉地图、攒装备 | 高风险高回报 |
| 敌人血量 | 原值（小兵 34 / 赤霄 1,400） | 全面上调（小兵 68 / 赤霄 2,400） |
| 敌人护甲 | 原值（机枪兵 4 级） | 穿甲的兵**甲级 +1**（机枪兵 5 级），封顶 5 级；突击兵仍无甲 |
| 敌人伤害 | 原值 | 杂兵与机枪 +23%～35%；狙击、火箭单发下调（38→32、48→40），改由更高血量施压 |
| 盾兵盾牌 | 120 | 140 |
| 玩家无敌帧 | 0.55s | 0.30s（被围攻时真的会掉血） |
| 物资容器 | 20 个，六种齐全 | 20 个，但军械箱 ×5、保险柜 ×5、工具箱 ×3，补给箱只剩 3 个 |
| 战利品品质 | 基准权重 | 普通货权重 ×0.42，史诗 ×1.9，传说/神话 ×3.2 |
| 首波增援 | 90s | 60s |
| 增援间隔 | 55 - 波次×2.5（下限 30s） | 45 - 波次×2（下限 28s） |
| 赤霄登场 | 第 5 波 | 第 4 波 |

实测（各 240 次保险柜）：史诗及以上占比从 32.6% 提到 60.2%，普通货从 36.7% 压到 11.2%；武器箱出史诗配件的概率翻了约 3 倍。机密图的敌人更硬，但好东西也真的更多。

在大厅「作战地图」里直接切换，卡片是红色调的那张就是机密。

| 换弹 | `R` |

## 干员

每个干员带 4 项能力：**G 战术道具 / V 小技能 / X 大招 / 被动**。技能不花钱买，选定后每局自带 —— 储备随开局回满，所以「储备 2 颗」是每局 2 颗。储备是**回充制**：手上有余量就能连放（只隔 0.55s 出弹间隔），打掉一层后按冷却慢慢回充下一层，放空了才需要等回充。

开局状态有一条硬规则：**G / V 不压初始冷却**，落地满储备、立刻能用；**X 一律带初始冷却** —— 普通大招开局就压满一整个 CD（外骨骼 90s / 虎蹲炮 70s / 侦察箭 75s / 巡飞弹 90s），激素枪则是开局 0 发、等第一个 30s 充能周期。落地谁都甩不了大招，先打节奏。

在大厅「作战装备」顶部的干员卡（或底部「干 员」按钮）里查看档案、切换出战干员。局内 HUD 底部正中是三格技能栏：冷却时压黑盖遮罩，储备用小圆点表示 —— 正在回充的那一层是扇形进度，右上角标回充秒数。

### 装备槽

出击前在大厅「作战装备」里配好，局内用数字键直接掏出来：

| 槽 | 能放什么 | 说明 |
| --- | --- | --- |
| `1` 主武器 | 冲锋枪 / 霰弹枪 / 步枪 / 射手步枪 / 狙击枪 | 主力输出 |
| `2` 副武器 | 同上，**同一把不能同时占两个槽** | 可以空着；多带一把能少跑一趟，但阵亡会一起丢 |
| `3` 近战 | 匕首 | 静音、不耗弹药、无视盾牌，槽位里必定有一把 |
| `4` 手枪 | G17 / 93R / G18 | 可以空着；没买手枪就只能靠刀 |
| `5` 医疗 | 六种医疗包 + 五种急救 / 止痛 + 三种手术包 | 三类共用一个槽；用剩的耐久和次数会带出局，全空了才掏不出来 |

三个枪槽各有各的弹药和换弹状态，切枪不会共享弹匣。阵亡会丢掉带进去的所有枪（**G17 也一样**）和装在枪上的配件，只有**刀不丢**。

### 医疗包

`5` 不是"一口回血"，而是**掏出来读一整条读条，读条长度由你这次缺多少血决定**。

```
总读条 = 启动时间 + ceil(缺口血量 ÷ 每秒回血)
```

例：血上限 100、当前只有 20 血，用战地箱（30 血/秒、启动 3.5s）→ 缺口 80，`80 ÷ 30 = 2.67` 向上取整 **3 秒**，所以一共读 **6.5s**；读满就是满血。缺得少就读得短 —— 只差 10 血的话，同一个箱子只读 3.5 + 1 = 4.5s。

时序（所有医疗包通用）：

```
按 5 / 左键 ──► 启动段（wind）──► 回血窗口（ceil(缺口/hps)）──► 血满 / 窗口走完 / 耐久耗尽 / 右键收手
                不回血，不能开枪、不能冲刺   每秒扣耐久 1:1 加血
                收手 = 白读，耐久一点不扣     收手 = 已灌进去的血留着，剩下的窗口作废
```

**中途打断是这套机制的核心**：战地箱读 6.5s，在第 5 秒（启动 3.5s + 回血 1.5s）右键收手，你已经拿到约 45 血；如果按整秒结算到了第 5.5 秒，就是回血 2 秒 = 60 血。剩下的 0.5s 窗口没了，耐久也按实际回血扣掉、不返还 —— 所以"能顶多久就顶多久，顶不住就跑"是合法打法。

- **长按 `5` 选物品**：按住 0.35s 弹出面板（只显示身上还有的），滚轮切换、**松开即用** —— 选完直接进启动读条，不用再补按一次；**短按 `5` 直接用手上那种**。面板分三组：医疗包 / 急救·止痛 / 手术包。新档默认第一种（简易注射器），之后记住你上次用的那种。
- **只有一个打断键：鼠标右键**。读条期和回血期都能随时掐掉（再按 `5` / 左键同样能收手）。**挨打、起跑、翻滚都不会自动中断** —— 想硬顶着子弹灌血可以，代价只有时间：读条期收手是白读（耐久一点没扣），回血期收手则丢掉已经灌进去的那部分耐久。把药收起来（切枪 / 切槽）当然也会停，但那只是药不在手上了。
- **一支用光就收手**：耐久见底不会自动拆下一支（否则多带几支 = 一次读条喝到满血），想接着灌得重新起手、再走一次启动读条。

新威胁的分工很清楚：**冰冻军团三兄弟管「跑不掉」，手雷兵管「躲不掉」** —— 投射兵在远处封路，投掷兵把冰圈画在你脚下，喷射兵贴脸糊你一脸冷雾。被霜区叠满冻伤的人躲不开红圈，被红圈逼出来的位置正好喂给机枪兵。增援第 2 波起出手雷兵、第 3 波起出喷射兵、第 4 波起出投射兵与投掷兵。

所有敌人都只驻守固定点位，视线被挡住就看不见你 —— 摸背身是这游戏的核心技巧。
近战不再是「贴身合体掉血」：敌人会先抬手（有可躲的预警窗口）、突进、再挥一刀，判定永远发生在双方体积之外。

## 地图编辑器

打开 `editor.html`，改动即时生效于预览。

| 操作 | 说明 |
| --- | --- |
| 滚轮 | 缩放视图 |
| 右键 / 中键 / 空格 + 左键 | 平移画布 |
| 左键点击 | 按当前工具放置（墙体为拖拽绘制） |
| 选择工具下拖拽 | 移动已放置的元素 |
| `Delete` | 删除选中 |
| 方向键 | 1px 微调 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+S` | 导出 JSON |

可编辑内容：墙体掩体、出生点（可多个，每局随机选一个）、物资容器（六种 + 随机）、撤离点（缺了会被拒绝校验）、敌人据点与兵种布点、地图尺寸与名称，以及**难度**（普通 / 机密）—— 选机密后导出的 JSON 会带上 `tier` 标记，游戏里加载就是机密数值。

右侧面板还有「随机生成」「检查」（越界 / 压墙 / 缺撤离点等校验）与三种输出：

- **导出 JSON**：下载 `.json`，在游戏大厅的「地图」面板导入。
- **写入本机游戏**：直接写进浏览器存储（`neonpurge_map_v1`），刷新游戏即可在大厅看到。若浏览器禁用了本地存储，用导出导入兜底。
- **在游戏中试玩**：新标签打开 `index.html`。

### 地图 JSON 结构

```jsonc
{
  "format": "neonpurge-map",
  "version": 1,
  "name": "零号大坝·普通",
  "tier": "standard",                                          // standard / secret（机密数值）
  "w": 4400, "h": 3200,
  "spawns":   [{ "x": 600, "y": 260 }],                       // 出生点，可多个
  "obstacles":[{ "x": 0, "y": 0, "w": 4400, "h": 140 }],      // 矩形墙体
  "crates":   [{ "x": 520, "y": 685, "t": "safe" }],          // t 省略 = 每局按权重随机
  "extracts": [{ "x": 2130, "y": 650, "name": "A" }],         // 至少一个
  "nests":    [{ "x": 1090, "y": 800 }],                      // 敌人据点
  "units":    [{ "x": 700, "y": 685, "type": "runner" }]      // 兵种布点
}
```

`type` 取值：`runner` / `shooter` / `brute` / `sniper` / `rocket` / `flamer` / `boss`。
导入时会自动夹紧越界坐标、把压墙的物件挪开，并给出警告而不是直接拒绝。

## 技术说明

- **渲染**：Canvas 2D，程序化绘制全部美术，没有任何图片资源。
- **音效**：WebAudio 实时合成（枪声、翻箱、脚步、撤离提示等），不加载音频文件。
- **架构**：单文件内按段落划分 —— 配置数据（武器 / 配件 / 容器 / 敌人 / 收集品）→ 输入 → 玩家与敌人 AI → 子弹与粒子 → 战利品与结算 → UI 面板。
- **存档**：`localStorage`

  | 键 | 内容 |
  | --- | --- |
  | `neonpurge_extract_v1` | 主存档：资金、已购武器、配件库、每把枪的装配、仓库收集品、统计 |
  | `neonpurge_map_v1` | 自定义地图（编辑器写入） |

  大厅右下角有「重置存档」，注意这会清空全部进度。

## 数值说明 / 已知取舍

- **节奏与移速**：两轮下调 —— 先把所有人的移动速度统一下调 20%（玩家走路 220→176，小兵追击 168→134，
  机枪兵 58→46、冰冻军团-投射兵 56→45、赤霄 96→77），再把玩家从 176 收到 **165**，并叠一层相机缩放（见下条）。
  玩家获得 `Shift` 跑步与体力系统（见「操作」与「护甲」两节），
  跑起来 244，短暂快过走路，但只够跑 6~7 秒；体力管理成了走位的一部分 —— 跑空不是「慢一点」，是 2.2 秒的力竭窗口（124，比最快的小兵 134 还慢），所以「什么时候停下回体力」和「什么时候开枪」一样要算。开镜移速按枪重分级（AWM 66 / R93 73 / SR9 91 / AKM 96 / M870 102 / M4A1 102 / AK-12 102 / QBZ-191 102 / 野牛 106 / QBZ-95 106 / QBZ-192 109 / 93R 129 / G17 132 / G18 142），最重的狙击枪开镜仍慢于小兵，需要架枪位置而不是边跑边打。
- **相机缩放**：`ZOOM = 0.85` —— 镜头拉远，一屏装下 1/0.85 ≈ 1.18 倍的世界，屏幕上的位移整体降 15%（角色 32px → 27px，4400×3200 的地图在 1366 窗口下约 2.7 屏宽）。世界内的所有比例（射程、弹速、AI 的 keep 距离、技能米数）一个都不动，所以它只改观感、不改平衡；改这一个常量就能回退。
- **地图扩建**：零号大坝从 3400×2400 扩到 **4400×3200**（面积 +72%）。老区（左上 3400×2400）一个实体都没动；右侧新增一条南北主街 + 四间带门仓库，下方新增「三横两带」的集装箱货场，**撤离点 B 挪到新区东南角** —— 想撤就得往里走。守军 33 → 51、箱子 20 → 34、巢穴 8 → 12，新增实体全部过了「不与墙重叠 + 从出生点可达」两项校验。
- **方向权重**：敌人 AI 的方向系数（盾兵侧移 0.7、机枪兵 0.5、狙击兵 0.38 等）会真实生效，不再被向量归一化抹平。
- **战斗节奏**：普通图小兵 34 血，M4A1 两发即倒，遭遇战以「抢先手」为主；机密图拉到 68 血，才有对枪过程。
- **增援**：普通图首波 90 秒、间隔递减到 30 秒；机密图首波 60 秒、间隔递减到 28 秒。增援只提升生命值（每波 +16%），不提升移速与反应。
- **机密护甲**：穿甲的兵甲级 +1（封顶 5 级），等于进机密图前得先把弹药整体提一档 —— 普通图用紫弹打机枪兵，机密图就得是金弹；赤霄顶到封顶后改加耐久（240 → 360）。
- **经济**：收集品要先撤离变现，阵亡则全部丢失 —— 机密图的收益更高，但要先扛住 2 倍血量的守军、再备好高一级的弹。
