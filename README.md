# NEON PURGE · 霓虹搜打撤

2D 俯视角「搜打撤」（Extraction Shooter）小游戏。你是一名进入阿萨拉坝区「零号大坝」的干员：翻箱倒柜搜物资、和驻守部队交火、然后活着走到撤离点。

纯前端单文件实现，**零依赖、零构建、双击即玩**（推荐 Chrome / Edge）。

---

## 快速开始

```bash
# 方式一：直接双击（无需任何环境）
index.html          # 游戏
editor.html         # 地图编辑器

# 方式二：本地起个静态服务（可选，便于同源共享浏览器存储）

# 然后访问 http://localhost:8080/index.html
```

仓库是纯静态资源，也可以直接在 GitHub 仓库的 Settings → Pages 里把 `main` 分支根目录发布成在线试玩页。

## 玩法循环

1. **大厅整备**：进「整备」界面（左装备 · 右仓库，按住直接拖 / 长按拿起）装主武器 / 副武器 / 手枪，从仓库穿上护甲、弹挂、背包，再把医疗物品和备弹装进弹挂 / 口袋 / 背包（都是一格一件、装格真扣仓库），再去「弹药」页按口径买弹、选弹级，最后选一张作战地图。
2. **出击**：进入封锁区，视野只有正面一片扇形，身后与掩体背面永远是雾；靠近容器按 `F` 搜刮，物品一件件翻出来。
3. **交战**：开枪会暴露位置，一个敌人发现你就会喊来周围所有人。**阵亡只保底近战武器**：身上带的枪（武器槽和背包里的都算）、护甲、弹挂、背包、所有格子和收集品一件不留 —— 撤离成功才算你的。
4. **撤离**：走到绿色撤离点站住 6 秒完成撤离，箱子里的东西才算真正到手。
5. **结算**：收集品先进仓库，**卖掉才变成资金**；资金用来买枪、护甲、弹药、补给。

**只有匕首永久保底**：新档一把枪都没有，G17 也要花 ¥700 去军火库买（或去局内缴获）。**子弹也要买**，而且打出去的、装进弹匣带进图的都算花掉了 —— 撤离不返还，阵亡也不返还。破产了可以先空手带刀出击，摸到枪再翻身。

## 四张图 · 三档难度

两大地形 × 阵营：**零号大坝（阿萨拉守军）** 与 **航天基地（哈夫克守军）**。两套守军共用同一套小兵与 AI，只有前缀名不同（哈夫克小兵 / 哈夫克盾兵……）；BOSS 各有各的：**阿萨拉是赤霄，哈夫克是安全总监**；两个阵营互相敌对、也都与玩家敌对 —— 自定义地图混编两个阵营时他们会互相开火（混战击杀不计入玩家击杀与分数）。

| 地图 | 阵营 | 难度 |
| --- | --- | --- |
| 零号大坝·普通 | 阿萨拉 | 普通（基准数值） |
| 零号大坝·机密 | 阿萨拉精锐 | 机密 |
| 航天基地·机密 | 哈夫克 | 机密 |
| 航天基地·绝密 | 哈夫克精锐 | **绝密**（比机密更硬，无普通档） |

难度阶梯：**普通 → 机密 → 绝密**。零号大坝永远不会刷哈夫克，航天基地全是哈夫克。

航天基地（6400×4600 五室菱形居中版）：地图**正中心**是**核心控制区** —— **总裁室**位于地图正中（大保险柜且重兵把守），四室呈菱形拱卫：**浮力室西北、蓝室东北、离心机室西南（全图物资最集中，点位最多）、黑室东南**，室间留环形走廊；西北角控制中心（控制大厅 + 天线阵）、北侧条带垂直总装厂房（火箭舱带门）与燃料罐区（六座球形储罐）、**东北角军械库**、**工业区**（东条带主厂房 + 储料罐）、西侧环形发射工位 A 与东南发射工位 B、西南机库群；南部**中控楼**（机房有保险柜，周边留大空场）与**宿舍区**（西南角，物资便宜，适合开局搜刮）。

航天基地撤离改革 —— **没有常规撤离点**：

1. **拉闸**：全图两处**总闸**（总裁室东门外走廊 / 发射工位 B 测控阵地），走近按 **E** 拉闸。每拉一处全场警报、哈夫克增援直扑你的位置。
2. **紧急撤离**：两处总闸全部拉下后启动 **5 分钟倒计时**，倒计时结束西门与东南跑道两个**紧急撤离点**开启，站进去 6 秒撤离。
3. **丢包撤离**：南门有一个丢包撤离点，**必须没有背包**才能走 —— 穿着背包时按 **E** 丢弃（背包里的东西一起丢掉）。

零号大坝保持常规撤离点不变。

## 干员

每个干员带 4 项能力：**G 战术道具 / V 小技能 / X 大招 / 被动**。技能不花钱买，选定后每局自带 —— 储备随开局回满，所以「储备 2 颗」是每局 2 颗。储备是**回充制**：手上有余量就能连放（只隔 0.55s 出弹间隔），打掉一层后按冷却慢慢回充下一层，放空了才需要等回充。

开局状态有一条硬规则：**G / V 不压初始冷却**，落地满储备、立刻能用；**X 一律带初始冷却** —— 普通大招开局就压满一整个 CD（外骨骼 90s / 虎蹲炮 70s / 侦察箭 75s / 巡飞弹 90s），激素枪则是开局 0 发、等第一个 30s 充能周期。落地谁都甩不了大招，先打节奏。

在大厅「作战装备」顶部的干员卡（或底部「干 员」按钮）里查看档案、切换出战干员。局内 HUD 底部正中是三格技能栏：冷却时压黑盖遮罩，储备用小圆点表示 —— 正在回充的那一层是扇形进度，右上角标回充秒数。

**两套伤害：身体伤害 vs 护甲伤害** —— 每把枪有两个独立数值，不再由同一个伤害派生：

- **身体伤害（dmg）**：打裸体、或打穿护甲之后进肉的伤害，决定 TTK 与 DPS —— 全部旧平衡不动；
- **护甲伤害（armorDmg）**：每发削掉多少护甲耐久，决定「磨穿重甲」要几发。**穿透时全额结算，被甲挡住（跳弹）只留 65%**，再乘弹级磨甲系数（修脚弹 ×0.55 → 顶级穿甲 ×1.38）。

由此产生两条清怪路线：**弹够硬直接吃肉**（贵、快），**弹不够就磨甲**（便宜、慢）—— 同一把 AKM 打 4 级甲机枪兵，3 级弹 2.46s、5 级弹 0.94s，差 2.6 倍；而磨甲最快的 QBZ-95 用 3 级弹只要 1.82s。霰弹 / 手枪打重甲要 6~10s（基本别硬打），野牛靠射速磨甲只慢 1.67 倍。护甲伤害在军火库卡片上有独立一行，并标着「4 级甲约 N 发磨穿」。

**六把老步枪不再同质化，新枪沿同一套轴扩编**：同样打 5 级弹、4 级甲机枪兵，近距 TTK 拉开到 **0.73（AS VAL）~ 1.12（QBZ-191）秒**，远距（900）则反转排序 —— 每把步枪都有 `role` 定位与 `fb`（远距衰减）参数：`d0` 内满伤，之后线性掉到 `min`，`d0 / min` 在军火库的「远距衰减」一行直接可查。想贴脸就 AKM / QBZ-192 / SR-3M，想架远就 QBZ-95 / QBZ-191 / K437，AS VAL / MCX 靠低噪音潜袭。

**机枪是第七个枪类**：RPK（40 匣）/ M249（100 弹箱）/ PKM（80 弹链 + 穿 2 人）—— 大弹容持续压制换来的代价是散布大、移速惩罚重、换弹 3~5.6 秒，架得住位置就是据点死神。冲锋枪补齐四条路子：MK4（9×19 均价泼水）、汤姆逊（.45 重手）、MP7（4.6 穿甲）、Vector（极限射速）；DMR 补 SKS / M14 / SR-25 三档半自动，狙击补 M700 栓动卡在 R93 与 AWM 中间。

## 整备（左装备 · 右仓库）

大厅的配装全部收进「整备」界面：**左边是出击装备，右边是仓库**，按住物品直接拖、拖到目标松手放置（也可按住不动 ~0.16s 拿起再拖）。

- **左侧装备槽**：主武器 / 副武器 / 手枪 / 近战四个武器槽，护甲 / 弹挂 / 背包三个穿着槽；下面是弹挂格 / 口袋格 / 背包格三排容器。点仓库里的东西拿在手上再点槽位放下，或者直接拖过去；点已装的槽位收回手上，右键同样收回。
- **右侧仓库**：武器（拥有的枪**按把数计**，装在槽里的不显示、备用件标「在库 ×n」）、护甲（按件数）、携行（弹挂 / 背包，备用件标「备用 ×n」）、弹药、医疗五个分区。**弹药区每个口径的每个上架弹级单独一行**（1 级弹和 4 级弹分开放、分开拿，选用级标「选用」），想只拿 4 级不拿 1 级直接拿那一行就行。**数量为 0 的东西一律不显示** —— 护甲 / 弹药 / 医疗只列自己有的，穿着中的护甲例外（显示「已穿」）。
- **弹挂 / 背包是实体物品**：不穿弹挂就没有备弹格、不穿背包就搜刮装不下 —— 都要从仓库「携行」区穿上；换着穿即时生效，格子不够的原物回仓。口袋是衣服自带的，永远 4 格。
- **配装预设**：整备页顶部 3 个槽，把当前「枪槽 / 近战 / 身上那件甲 / 弹挂 / 背包 / 上次用的药」存成一套，换装时点「套用」一键换回；套用前先查仓库，缺件会列出来并整单不执行（不会套一半）。预设不含弹挂 / 背包里装的东西 —— 那些还是一键整备 / 手动补。
- **一键整备**：先把拥有的最好弹挂 / 背包穿上，再补满弹药格、给已拥有口径补格、把绷带 / 止痛 / 医疗包塞进空格；**全部卸下**原物回仓。
- **大厅「作战装备」卡**只显示摘要，点「进入整备」进界面配装。

## 背包 · 弹挂 · 口袋

身上有三个容器，**装格即扣仓库、撤离原样带回、阵亡全部清空**：

| 容器 | 格数 | 快捷可用 | 说明 |
| --- | --- | --- | --- |
| 弹挂 | 穿着弹挂的格数（8 / 12…） | ✅ 按 5 / R 都认 | 药品、弹药、收集品、配件都能放 |
| 口袋 | 4（固定） | ✅ 按 5 / R 都认 | 一格一件，最适合塞绷带和止痛 |
| 背包 | 穿着背包的格数（0 / 4 / 8…） | ❌ 只能中转 | 搜刮先堆这里，Tab 里倒进弹挂才能用；**枪也能放** |

- **格子规则**：一格一件（一支注射器 = 一格、一片止痛 = 一格）；弹药格按口径 **+ 弹级** 装，同口径不同弹级分格放，一格上限 = 该口径最大弹匣 × 2 发。医疗包的剩余耐久、手术包的剩余次数都留在格子里。
- **大厅「整备」**：**按住物品直接拖**（不用等长按），拖到槽位 / 格子松手放置；也可按住不动 ~0.16s 拿起再拖（手持跟随指针）。拖到目标上会高亮合法落点（容器格只收小物件，枪只进背包，装备要拖到对应装备槽）；空处松手放回原位置（装备回仓库并提示），拖进右侧仓库放回仓库；装备槽右键脱下回仓、格子物品右键回仓（用剩的耐久 / 次数 / 发数都保留）。**穿着 / 已装的装备从仓库列表再拿会先脱下**（不搞「身上一把手上一把」的副本）；丢 pointerup（窗外松手 / 切窗口）会自动收场，`Esc` 随时脱手，卡死状态重开界面或按一下即自愈。
- **局内 Tab**：打开背包整理（**时间不暂停**——世界继续在动，**被打了背包会被立刻拍掉**；面板开着时局内按键全封、不会背着面板瞎走）。**只认拖动**：按住 ~0.16s 或按下拖 10px 拿起，**单击左键不拿起也不放置**（防误点把东西拿在手上甚至弄丢）。拖到屏幕最右侧的红色**丢弃区**松手 = 把这件东西扔到地上（可以再捡回来；枪丢地上且别处没有第二把就真的丢了）。**同口径同弹级的弹药拖到一起自动合并**（补满一格为止，装不下的留在拖动的那格）。背包里能放枪 / 弹药 / 收集品 / 配件 —— 什么都行，但**背包里的药不能直接用**，要先倒进弹挂或口袋。
  - **局内穿甲**：背包面板顶部有**护甲槽** —— 把背包里的护甲拖上去直接穿上（身上那件耐久原样换到手上，可再塞回背包 / 丢地上 / 留着穿回）；**右键背包里的护甲** = 直接穿上（身上那件换回格子），**右键护甲槽** = 脱下到手上。\n  - **局内弹挂 / 背包槽**：面板顶部有**弹挂槽 + 背包槽** —— 拖装备上去直接换穿（旧的下到手上，**里面的东西跟着装备走**）；点住或右键 = 脱下到手上，拖到丢弃区 = 连包带物一起丢。\n  - **地上装备：拾取 / 搜索**：脱下或换下的弹挂 / 背包掉在地上，提示 **[F] 拾取 · [H] 搜索** —— `F` 直接换穿（同款 = 备用件，里面的东西并入身上容器）；`H` 打开搜索面板逐件翻（保耐久 / 保剩余次数），没拿走的原样留在装备里。`E` 仍专管拉总闸 / 丢包。\n  - **地面物资搜索**：周围 **≥2 件掉落**（叠在一起看不清也行）按 `H` 打开「地面物资」面板 —— 每件掉落一行（弹药 / 药品 / 收集品 / 枪 / 甲 / 装备都认），**开面板即全部翻开、不用等搜索**，**滚轮选中、`F` 捡走选中的那件**；捡不下的行标「带不走」不掉物品，没收的留在地上随时再搜。单件掉落直接 `F` 更快，不开面板。

  - **护甲兜底换穿**：翻箱 / 捡地上护甲时背包满了？**直接换穿** —— 身上那件（耐久原样）掉在脚边，不再「带不走」。**只升不降**：裸奔 / 更高级 / 同级更大容量才自动换，捡更差的甲会照常提示带不走（要换可以 Tab 里手动穿）。
  - **没背包也能捡枪**：地上 / 箱里的枪，武器槽有空位直接装上；槽全占着就和**手上这把换** —— 旧枪掉在脚边（弹匣余量保留，随时捡回来），不再被「身上没有空位」卡住。
- **搜刮入袋**：搜到的一切都占格子 —— 收集品、配件、枪也一样（枪先装空的武器槽，没槽了收进背包）。先背包、再弹挂 / 口袋；身上一格都没有就「拿不走」，东西留在箱子里，回来还能接着拿。
- **快捷键只认弹挂和口袋**：按 5 的自动用药阶梯、R 换弹，都只读这两个容器；背包里的东西 Tab 倒出来才算数。

配套规则：

- **军火库只卖上架的级别**：没上架的弹级连卡片都不渲染，区块标题会写「上架 0 级 ~ X 级」；直接调购买接口也会被拒绝。

机密模式的规则是「穿甲的兵甲级 +1，封顶 5 级」：

- **突击兵不升**。它本来就不穿甲，保持裸奔才能让 0 级 RIP 修脚弹一直有舞台，也保住「小兵一枪一个」的手感。

### 自动用药阶梯（短按 `5`）

短按 `5` 不再"用手上那种"，而是按四条优先级现查一遍，**上一条身上没货就顺延到下一条**：

| 顺序 | 条件 | 选谁 | 为什么排这儿 |
| --- | --- | --- | --- |
| ① 止血 | 身上有流血 | 流血 ≥2 层且带止血带 → **止血带**；否则有绷带 → **绷带**；只剩止血带 → 止血带 | 流血时包扎效率只有 0.75 折，血一边灌一边漏，先止住再谈别的 |
| ② 止痛 | 有骨伤 / 贯穿伤，且止痛已过期 | 缓释片 → 抗生素 → DVE 片（**便宜的先吃**） | 一片药 3~4 秒，动刀要 5~10 秒；先止疼再慢慢缝更安全 |
| ③ 手术 | 有贯穿伤 / 骨折 / 骨裂 | 简易手术 → 战术手术 → DEK 手术（价低先用） | 贯穿伤压着血量上限，不先缝上，血灌到上限也到不了 100 |
| ④ 回血 | 血量没满 | 先接着烧**已经拆开的那支**（`left > 0`）；都是没拆封的才按「上次那种 → 第一支有货的」拆新的 | 拆封的耐久已经是你的了，不烧完等于扔钱 |

细节：

- **纯掉血不算「需要止痛」**：止痛压的是骨伤负面和贯穿伤黑边，外加打架时 -10% 受伤。没骨伤没贯穿伤时不会为了那 10% 偷偷吃你一片药 —— 想主动吃就长按 `5` 手动挑。
- **药效还在就不重复吃**（止痛不叠加，吃了只是烧库存）。
- **四步都没理由动手就什么都不做**，不会为了"按了键"硬掏一支医疗包。
- 想指定某一种，长按 `5` 自己挑：那条路径跳过阶梯，选谁用谁。

### 医疗包

`5` 不是"一口回血"，而是**掏出来读一整条读条，读条长度由你这次缺多少血决定**。

```
总读条 = 启动时间 + ceil(缺口血量 ÷ 每秒回血)
```

例：血上限 100、当前只有 20 血，用战地箱（30 血/秒、启动 3.5s）→ 缺口 80，`80 ÷ 30 = 2.67` 向上取整 **3 秒**，所以一共读 **6.5s**；读满就是满血。缺得少就读得短 —— 只差 10 血的话，同一个箱子只读 3.5 + 1 = 4.5s。

时序（所有医疗包通用）：

```
按 5 / 左键 ──► 启动段（wind）──► 回血窗口（ceil(缺口/hps)）──► 血满 / 窗口走完 / 耐久耗尽 / 右键收手
                不回血，不能开枪、不能冲刺   每秒扣耐久 1:1 加血
                收手 = 白读，耐久一点不扣     收手 = 已灌进去的血留着，剩下的窗口作废
```

**中途打断是这套机制的核心**：战地箱读 6.5s，在第 5 秒（启动 3.5s + 回血 1.5s）右键收手，你已经拿到约 45 血；如果按整秒结算到了第 5.5 秒，就是回血 2 秒 = 60 血。剩下的 0.5s 窗口没了，耐久也按实际回血扣掉、不返还 —— 所以"能顶多久就顶多久，顶不住就跑"是合法打法。

几条规则：

- **耐久是留在局内的**：血满了就自动停手，剩下的耐久跟着你撤离（阵亡则整包丢掉）。一支 800 点的大箱子能撑好几场遭遇战。
- **短按 `5` = 自动用药**：按 `① 止血 → ② 止痛 → ③ 手术 → ④ 回血` 的严格顺序，现查身体状态挑一件开始用（详见下方「自动用药阶梯」）。状态正常时不会浪费任何东西，只弹一行「状态正常 · 没有要处理的伤」。
- **长按 `5` 选物品**：按住 0.35s 弹出面板（只显示身上还有的），滚轮切换、**松开即用** —— 选完直接进启动读条，不用再补按一次；打开时默认高亮「推荐」那件（就是短按会自动选的那件）。面板分三组：医疗包 / 急救·止痛 / 手术包。
- **按 `5` 不切槽**：治疗在原地发生 —— 枪一直拿在手上（画面里是药在手上），只是治疗期间左键不出枪、G/V/X 不响应、不能冲刺，走路慢 8%（车载包免减速）。结束（打完 / 收手）后如果之前端着的是医疗槽（滚轮切过去的），自动换回之前的枪。
- **只有一个打断键：鼠标右键**。读条期和回血期都能随时掐掉（再按 `5` / 左键同样能收手）。**挨打、起跑、翻滚都不会自动中断** —— 想硬顶着子弹灌血可以，代价只有时间：读条期收手是白读（耐久一点没扣），回血期收手则丢掉已经灌进去的那部分耐久。把药收起来（切枪 / 切槽）当然也会停，但那只是药不在手上了。
- **一支用光就收手**：耐久见底不会自动拆下一支（否则多带几支 = 一次读条喝到满血），想接着灌得重新起手、再走一次启动读条。
- **医疗箱**（户外 / 战地）读条走完会顺带止痛 30s / 60s，并**一把压住全部流血层**（每压 1 层额外扣 12 点箱耐久）—— 止痛是附赠，不能替代止痛药；身上没绷带 / 止血带时，短按 5 的自动阶梯也会用它来止血。
- 医疗槽掏出东西时移速 ×0.92（**车载急救包例外**：挂水不减速），右键随时收手。

### 创伤

挨打不只是掉血。单次伤害越重越可能挂上创伤，每种都有自己的处理方式 —— **止痛药不是万能的**。

| 创伤 | 效果 | 怎么处理 |
| --- | --- | --- |
| 流血（最多 6 层） | 每层每秒掉 0.9 血，**最低锁 1 血**，不会自己流死；移速、包扎效率一起打折 | 弹力绷带（1 层）/ 止血带（全部）；止痛药压不住 |
| 贯穿伤 · 头 / 胸 / 腹（每处 2 层） | 每层 **-10% 血量上限**，屏幕压黑边、视野发糊 | 手术包；止痛只把黑边压淡 |
| 手臂骨折 | 开镜慢 60%、换弹慢 35%、打药读条慢 30%、散布 ×1.35、移速 -4% | 手术包；止痛可临时屏蔽全部负面 |
| 腿部骨折 | 移速 ×0.60 | 手术包；止痛只淡一点画面，跑不动还是跑不动 |
| 骨裂（最多 2 层） | 每层再 -12% 移速（叠在腿断之上） | 手术包；止痛完全无效 |
| 虚弱 | 被队友拉起后 -20% 血量上限，本局不可逆 | 目前没有救起流程，代码里留了 `applyWeak()` 入口 |

触发规则（按单次伤害算，烧伤按每一跳算）：

- `≥9`：55% 挂 1 层流血；`≥30`：72% 挂 2 层
- `≥24`：30% 挂 1 层贯穿伤（随机部位）
- `≥20`：18% 手臂骨折；`≥26`：另有 14% 腿部骨折
- 流血锁 1 血、贯穿伤压上限，两者都不会直接把人打死 —— 真打死你的还是子弹

新威胁的分工很清楚：**冰冻军团三兄弟管「跑不掉」，手雷兵管「躲不掉」** —— 投射兵在远处封路，投掷兵把冰圈画在你脚下，喷射兵贴脸糊你一脸冷雾。被霜区叠满冻伤的人躲不开红圈，被红圈逼出来的位置正好喂给机枪兵。增援第 2 波起出手雷兵、第 3 波起出喷射兵、第 4 波起出投射兵与投掷兵。

所有敌人都只驻守固定点位，视线被挡住就看不见你 —— 摸背身是这游戏的核心技巧。
近战不再是「贴身合体掉血」：敌人会先抬手（有可躲的预警窗口）、突进、再挥一刀，判定永远发生在双方体积之外。

## 地图编辑器

打开 `editor.html`，改动即时生效于预览。

| 操作 | 说明 |
| --- | --- |
| 滚轮 | 缩放视图 |
| 右键 / 中键 / 空格 + 左键 | 平移画布 |
| 左键点击 | 按当前工具放置（墙体为拖拽绘制） |
| 选择工具下拖拽 | 移动已放置的元素 |
| `Delete` | 删除选中 |
| 方向键 | 1px 微调 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+S` | 导出 JSON |

可编辑内容：墙体掩体、出生点（可多个，每局随机选一个）、物资容器（六种 + 随机）、撤离点（缺了会被拒绝校验）、敌人据点与兵种布点、地图尺寸与名称，以及**难度**（普通 / 机密）—— 选机密后导出的 JSON 会带上 `tier` 标记，游戏里加载就是机密数值。

右侧面板还有「随机生成」「检查」（越界 / 压墙 / 缺撤离点等校验）与三种输出：

- **导出 JSON**：下载 `.json`，在游戏大厅的「地图」面板导入。
- **写入本机游戏**：直接写进浏览器存储（`neonpurge_map_v1`），刷新游戏即可在大厅看到。若浏览器禁用了本地存储，用导出导入兜底。
- **在游戏中试玩**：新标签打开 `index.html`。

### 地图 JSON 结构

```jsonc
{
  "format": "neonpurge-map",
  "version": 1,
  "name": "零号大坝·普通",
  "tier": "standard",                                          // standard / secret（机密数值）
  "w": 4400, "h": 3200,
  "spawns":   [{ "x": 600, "y": 260 }],                       // 出生点，可多个
  "obstacles":[{ "x": 0, "y": 0, "w": 4400, "h": 140 }],      // 矩形墙体
  "crates":   [{ "x": 520, "y": 685, "t": "safe" }],          // t 省略 = 每局按权重随机
  "extracts": [{ "x": 2600, "y": 1180, "name": "A" }],        // 至少一个
  "nests":    [{ "x": 1090, "y": 800 }],                      // 敌人据点
  "units":    [{ "x": 700, "y": 685, "type": "runner" }],     // 兵种布点
  "regions":  [{ "x": 2040, "y": 1360, "w": 1000, "h": 780,
                 "name": "主变电站" }]                        // 地区标注（可选，≤10 块）
}
```

`regions` 是可选的地区标注：局内地面上画虚线框与半透明地区名（随光照显现）、
右上角小地图上常驻小字地名，玩家进入新地区时屏幕上方弹出「进入地区」横幅。
非法条目（缺坐标 / 名字为空 / 面积太小 / 越界）导入时直接丢弃，不影响载入。

`bossZone` 是可选的 BOSS 驻守区（≥140×140）：带上之后 BOSS 无论初始布点还是
增援波都刷在这个矩形里，移动被硬锁在内（击退 / 翻滚也推不出去），拴绳目标也
落在区内 —— 零号大坝用它把赤霄关在行政楼大厅，想打 BOSS 就得进楼。

`type` 取值：`runner` / `shooter` / `brute` / `sniper` / `rocket` / `flamer` / `boss`。
导入时会自动夹紧越界坐标、把压墙的物件挪开，并给出警告而不是直接拒绝。

## 技术说明

- **渲染**：Canvas 2D，程序化绘制全部美术，没有任何图片资源。
- **音效**：WebAudio 实时合成（枪声、翻箱、脚步、撤离提示等），不加载音频文件。
- **架构**：单文件内按段落划分 —— 配置数据（武器 / 配件 / 容器 / 敌人 / 收集品）→ 输入 → 玩家与敌人 AI → 子弹与粒子 → 战利品与结算 → UI 面板。
- **存档**：`localStorage`

  | 键 | 内容 |
  | --- | --- |
  | `neonpurge_extract_v1` | 主存档：资金、已购武器、配件库、每把枪的装配、仓库收集品、统计 |
  | `neonpurge_map_v1` | 自定义地图（编辑器写入） |

  大厅右下角有「重置存档」，注意这会清空全部进度。

## 数值说明 / 已知取舍

- **节奏与移速**：两轮下调 —— 先把所有人的移动速度统一下调 20%（玩家走路 220→176，小兵追击 168→134，
  机枪兵 58→46、冰冻军团-投射兵 56→45、赤霄 96→77），再把玩家从 176 收到 **165**，并叠一层相机缩放（见下条）。
  玩家获得 `Shift` 跑步与体力系统（见「操作」与「护甲」两节），
  跑起来 244，短暂快过走路，但只够跑 6~7 秒；体力管理成了走位的一部分 —— 跑空不是「慢一点」，是 2.2 秒的力竭窗口（124，比最快的小兵 134 还慢），所以「什么时候停下回体力」和「什么时候开枪」一样要算。开镜移速按枪重分级（AWM 66 / R93 73 / SR9 91 / AKM 96 / M870 102 / M4A1 102 / AK-12 102 / QBZ-191 102 / 野牛 106 / QBZ-95 106 / QBZ-192 109 / 93R 129 / G17 132 / G18 142），最重的狙击枪开镜仍慢于小兵，需要架枪位置而不是边跑边打。
- **相机缩放**：`ZOOM = 0.85` —— 镜头拉远，一屏装下 1/0.85 ≈ 1.18 倍的世界，屏幕上的位移整体降 15%（角色 32px → 27px，4400×3200 的地图在 1366 窗口下约 2.7 屏宽）。世界内的所有比例（射程、弹速、AI 的 keep 距离、技能米数）一个都不动，所以它只改观感、不改平衡；改这一个常量就能回退。
- **地图扩建**：零号大坝从 3400×2400 扩到 **4400×3200**（面积 +72%）。老区（左上 3400×2400）一个实体都没动；右侧新增一条南北主街 + 四间带门仓库，下方新增「三横两带」的集装箱货场，**撤离点 B 挪到新区东南角** —— 想撤就得往里走。守军 33 → 51、箱子 20 → 34、巢穴 8 → 12，新增实体全部过了「不与墙重叠 + 从出生点可达」两项校验。
- **地区重规划**：参照《三角洲行动》零号大坝把全图重排成十个地区 —— 北缘**大坝坝顶**（闸门塔 + 三处过坝口不变），西北**管道区域**（输水管阵列 / 泵房 / 储油罐）、**军营**（三排营房 / 食堂 / 军械库），坝体正下方**行政辖区**（围合庭院 + 主楼 + 三座南翼楼，撤离点 A 在坝下广场、赤霄常驻大厅），西面**水泥厂**（主厂房 / 四筒仓 / 传送带 / 装车台 / 料仓 / 轨道），**泄洪河谷**纵贯西南（两岸堤墙留过河缺口，河床有断桥桥墩 / 涵洞 / 排水阶梯 / 巨石群，南口有出生点），中央**主变电站**（围栏留四门 + 可进入的主控楼 + 两排变压器 + 防火墙 / 电缆沟 / 构架塔），东南**游客中心**（可进入的主展厅 + 纪念品店 + 停车场 + 连廊，撤离点 B 仍在东南角），东侧乱石**坡地**（盘山路挡墙 + 巨石群 + 岩缝），南面**南货场**（旧集装箱堆场改建：货柜排 / 装卸台 / 地磅房，出生点⑥所在，撤离点 B 旁）。旧「集装箱堆场」与东部大围场拆除，物资集中进各地区；全图 249 块障碍、**容器 44 / 守军 58**（生成器校验强制每个容器 / 据点 / 守军都必须落在某个地区里），各地区都过了**复杂度校验**（块数 ≥16 且覆盖率适中，只有坝顶长廊与河谷主通道保持开阔）。生成器 `.workbuddy/gen_zero_dam.js` 自动做压墙 / 过近 / 连通性 / BOSS 驻守区四项校验。
- **增援闸门随驻军规模伸缩**：增援波与「呼叫增援」的场上人数上限不再写死 42 —— 改为 `G.enemyCap = max(42, 开局守军数 + 8)`，在每局开场按地图驻军重设。修复零号大坝扩图后守军 51（开局 57）越过 42 上限、增援波被开局人数掐死（必须先杀 15 人才可能来第一波）的静默回归 bug。
- **方向权重**：敌人 AI 的方向系数（盾兵侧移 0.7、机枪兵 0.5、狙击兵 0.38 等）会真实生效，不再被向量归一化抹平。
- **战斗节奏**：普通图小兵 34 血，M4A1 两发即倒，遭遇战以「抢先手」为主；机密图拉到 68 血，才有对枪过程。
- **增援**：普通图首波 90 秒、间隔递减到 30 秒；机密图首波 60 秒、间隔递减到 28 秒。增援只提升生命值（每波 +16%），不提升移速与反应。
- **机密护甲**：穿甲的兵甲级 +1（封顶 5 级），等于进机密图前得先把弹药整体提一档 —— 普通图用紫弹打机枪兵，机密图就得是金弹；赤霄顶到封顶后改加耐久（240 → 360）。
- **经济**：收集品要先撤离变现，阵亡则全部丢失 —— 机密图的收益更高，但要先扛住 2 倍血量的守军、再备好高一级的弹。
