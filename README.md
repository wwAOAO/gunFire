# NEON PURGE · 霓虹搜打撤

2D 俯视角「搜打撤」（Extraction Shooter）小游戏。你是一名进入阿萨拉坝区「零号大坝」的干员：翻箱倒柜搜物资、和驻守部队交火、然后活着走到撤离点。

纯前端单文件实现，**零依赖、零构建、双击即玩**（推荐 Chrome / Edge）。

---

## 快速开始

```bash
# 方式一：直接双击（无需任何环境）
index.html          # 游戏
editor.html         # 地图编辑器

# 方式二：本地起个静态服务（可选，便于同源共享浏览器存储）
python -m http.server 8080
# 然后访问 http://localhost:8080/index.html
```

仓库是纯静态资源，也可以直接在 GitHub 仓库的 Settings → Pages 里把 `main` 分支根目录发布成在线试玩页。

## 玩法循环

1. **大厅整备**：挑主武器、护甲、补给（医疗包 / 手雷 / 弹药包），再去「弹药」页按口径买弹、选弹级，最后选一张作战地图。
2. **出击**：进入封锁区，视野只有正面一片扇形，身后与掩体背面永远是雾；靠近容器按 `E` 搜刮，物品一件件翻出来。
3. **交战**：开枪会暴露位置，一个敌人发现你就会喊来周围所有人。被打死等于全部携带装备和包里收集品蒸发。
4. **撤离**：走到绿色撤离点站住 6 秒完成撤离，箱子里的东西才算真正到手。
5. **结算**：收集品先进仓库，**卖掉才变成资金**；资金用来买枪、护甲、弹药、补给。

**只有匕首永久保底**：新档一把枪都没有，G17 也要花 ¥700 去军火库买（或去局内缴获）。**子弹也要买**，而且打出去的、装进弹匣带进图的都算花掉了 —— 撤离不返还，阵亡也不返还。破产了可以先空手带刀出击，摸到枪再翻身。

## 两张图 · 两种难度

内置地图有且只有一张地形（零号大坝），但给了两套数值：

| | 零号大坝·普通 | 零号大坝·机密 |
| --- | --- | --- |
| 定位 | 熟悉地图、攒装备 | 高风险高回报 |
| 敌人血量 | 原值（小兵 34 / 赤霄 1,400） | 全面上调（小兵 68 / 赤霄 2,400） |
| 敌人伤害 | 原值 | 杂兵与机枪 +23%～35%；狙击、火箭单发下调（38→32、48→40），改由更高血量施压 |
| 盾兵盾牌 | 120 | 140 |
| 玩家无敌帧 | 0.55s | 0.30s（被围攻时真的会掉血） |
| 物资容器 | 20 个，六种齐全 | 20 个，但军械箱 ×5、保险柜 ×5、工具箱 ×3，补给箱只剩 3 个 |
| 战利品品质 | 基准权重 | 普通货权重 ×0.42，史诗 ×1.9，传说/神话 ×3.2 |
| 首波增援 | 90s | 60s |
| 增援间隔 | 55 - 波次×2.5（下限 30s） | 45 - 波次×2（下限 28s） |
| 赤霄登场 | 第 5 波 | 第 4 波 |

实测（各 240 次保险柜）：史诗及以上占比从 32.6% 提到 60.2%，普通货从 36.7% 压到 11.2%；武器箱出史诗配件的概率翻了约 3 倍。机密图的敌人更硬，但好东西也真的更多。

在大厅「作战地图」里直接切换，卡片是红色调的那张就是机密。

### 装备槽

出击前在大厅「作战装备」里配好，局内用数字键直接掏出来：

| 槽 | 能放什么 | 说明 |
| --- | --- | --- |

### 医疗包

`5` 不是"一口回血"，而是**掏出来读条、再按每秒回血慢慢灌**。每种包都有三组数：**耐久**（这一支总共能回多少血）、**回血速度**（读条走完之后每秒灌多少）、**启动时间**（读条，期间一滴血都不回，被打断就白读）。

| 医疗包 | 耐久 | 回血 | 启动 | 附加 | 价格 |
| --- | --- | --- | --- | --- | --- |
| 简易注射器 | 30 | 5 血/秒 | 3.5s | — | ¥280 |
| 强效注射器 | 60 | 12 血/秒 | 3.0s | 打架首选，读条最短 | ¥900 |
| 车载急救包 | 90 | 6 血/秒 | 5.0s | 挂水时顺带回体力 | ¥1,000 |
| 野战急救包 | 220 | 20 血/秒 | 6.0s | 读条最长，只适合战后 | ¥1,900 |
| 户外医疗箱 | 350 | 20 血/秒 | 4.0s | 治伤口 + 30s 止痛 | ¥3,200 |
| 战地医疗箱 | 800 | 30 血/秒 | 3.5s | 治伤口 + 60s 止痛 | ¥6,000 |

几条规则：

- **耐久是留在局内的**：血满了就自动停手，剩下的耐久跟着你撤离（阵亡则整包丢掉）。一支 800 点的大箱子能撑好几场遭遇战。
- **长按 `5` 选物品**：按住 0.35s 弹出面板（只显示身上还有的），滚轮切换、松开确认；**短按 `5` 直接用手上那种**。面板分三组：医疗包 / 急救·止痛 / 手术包。新档默认第一种（简易注射器），之后记住你上次用的那种。
- **医疗箱**（户外 / 战地）读条走完会顺带止痛 30s / 60s —— 那是附赠，不能替代止痛药。
- 医疗槽掏出东西时移速 ×0.92，左键或再按 `5` 可以随时停手；换槽 / 切枪会自动中断。

### 创伤

挨打不只是掉血。单次伤害越重越可能挂上创伤，每种都有自己的处理方式 —— **止痛药不是万能的**。

| 创伤 | 效果 | 怎么处理 |
| --- | --- | --- |
| 流血（最多 6 层） | 每层每秒掉 0.9 血，**最低锁 1 血**，不会自己流死；移速、体力回复、包扎效率一起打折 | 弹力绷带（1 层）/ 止血带（全部）；止痛药压不住 |
| 贯穿伤 · 头 / 胸 / 腹（每处 2 层） | 每层 **-10% 血量上限**，屏幕压黑边、视野发糊 | 手术包；止痛只把黑边压淡 |
| 手臂骨折 | 开镜慢 60%、换弹慢 35%、打药读条慢 30%、散布 ×1.35、移速 -4% | 手术包；止痛可临时屏蔽全部负面 |
| 腿部骨折 | **不能冲刺**、移速 ×0.60 | 手术包；止痛只淡一点画面，跑不动还是跑不动 |
| 骨裂（最多 2 层） | 腿断着强行冲刺触发，每层再 -12% 移速 | 手术包；止痛完全无效 |
| 虚弱 | 被队友拉起后 -20% 血量上限，本局不可逆 | 目前没有救起流程，代码里留了 `applyWeak()` 入口 |

触发规则（按单次伤害算，烧伤按每一跳算）：

- `≥9`：55% 挂 1 层流血；`≥30`：72% 挂 2 层
- `≥24`：30% 挂 1 层贯穿伤（随机部位）
- `≥20`：18% 手臂骨折；`≥26`：另有 14% 腿部骨折
- 腿断时按 `Shift` 会硬冲一下（半速、照样耗体力），并立刻坐实 1 层骨裂
- 流血锁 1 血、贯穿伤压上限，两者都不会直接把人打死 —— 真打死你的还是子弹

急救件和手术包跟医疗包共用 `5` 号槽，长按 `5` 打开的面板里分三组。

| 止血带（绿） | 止住全部流血层 | 2.6s | 1 | ¥320 |

| 手术包 | 次数 | 单次读条 | 价格 |
| --- | --- | --- | --- |
| 简易手术包（白） | 2 次 | 10s | ¥1,600 |

## 改枪系统

配件是**物资**而不是解锁 —— 只能在地图里的工具箱、保险柜等容器里搜出来，撤离成功才会进配件库；阵亡会随机丢掉一些。

5 个槽位，共 15 件配件，效果全部是乘算系数，装上立刻反映在中栏剪影和右侧数据上：

| 槽位 | 普通 | 稀有 | 史诗 |
| --- | --- | --- | --- |
| 枪口 MUZZLE | — | 消音器 | 战术补偿器 / 加长枪管 |
| 瞄具 OPTIC | 红点镜 | 全息镜 | 四倍镜 |
| 握把 GRIP | 轻型握把 | 垂直握把 | 激光指示器 |
| 弹匣 MAG | 轻量弹匣 | 扩容弹匣 | 速拔弹匣 |
| 枪托 STOCK | 折叠枪托 | 重型枪托 | 战术枪托 |

手枪（G17 / 93R / G18）只有 4 个槽位，枪托槽显示为「不适用」，改装台上的计数也是 `/4`。装件之后枪的侧视外形会跟着变：消音器变粗筒、瞄具加长、扩容弹匣更长、战术枪托多一道绿线。

## 物资容器

容器分六种，翻找速度和产出完全不同，**品质越高翻得越慢**（普通货约 1 秒，神话货要蹲近 5 秒）。

| 容器 | 翻找倍率 | 产出 | 动静 |
| --- | --- | --- | --- |
| 弹药箱 AMMO CRATE | 0.55（最快） | 备弹与手雷，不占背包 | 无声 |
| 医疗箱 MEDICAL BOX | 0.70 | 一整箱医疗包，偶尔混一件货 | 无声 |
| 工具箱 TOOLBOX | 0.85 | 改枪配件的主要来源 | 噪音 220 |
| 补给箱 SUPPLY CRATE | 1.00 | 杂项：收集品 / 药 / 弹 / 偶尔一把枪 | 无声 |
| 武器箱 WEAPON CASE | 1.35 | 必出一把枪（已拥有则转备弹） | 噪音 470 |
| 保险柜 SAFE | 1.55（最慢） | 高品质货与史诗配件，最肥 | 噪音 540 |

铁柜和军械箱开起来是有动静的：附近的巡逻兵会循声过来查看。

收集品 16 件，分 5 个品质档（普通 → 稀有 → 史诗 → 传说 → 神话），最贵的「赤霄反应核心」卖 ¥34,000。

机密图的容器构成被重排成「军械为主」：5 个武器箱、5 个保险柜、3 个工具箱、3 个补给箱、2 个医疗箱、2 个弹药箱 —— 好翻的箱子变少，值钱的箱子变多。

| --- | --- | --- | --- |

## 地图编辑器

打开 `editor.html`，改动即时生效于预览。

| 操作 | 说明 |
| --- | --- |
| 滚轮 | 缩放视图 |
| 右键 / 中键 / 空格 + 左键 | 平移画布 |
| 左键点击 | 按当前工具放置（墙体为拖拽绘制） |
| 选择工具下拖拽 | 移动已放置的元素 |
| `Delete` | 删除选中 |
| 方向键 | 1px 微调 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+S` | 导出 JSON |

可编辑内容：墙体掩体、出生点（可多个，每局随机选一个）、物资容器（六种 + 随机）、撤离点（缺了会被拒绝校验）、敌人据点与兵种布点、地图尺寸与名称，以及**难度**（普通 / 机密）—— 选机密后导出的 JSON 会带上 `tier` 标记，游戏里加载就是机密数值。

右侧面板还有「随机生成」「检查」（越界 / 压墙 / 缺撤离点等校验）与三种输出：

- **导出 JSON**：下载 `.json`，在游戏大厅的「地图」面板导入。
- **写入本机游戏**：直接写进浏览器存储（`neonpurge_map_v1`），刷新游戏即可在大厅看到。若浏览器禁用了本地存储，用导出导入兜底。
- **在游戏中试玩**：新标签打开 `index.html`。

### 地图 JSON 结构

```jsonc
{
  "format": "neonpurge-map",
  "version": 1,
  "name": "零号大坝·普通",
  "tier": "standard",                                          // standard / secret（机密数值）
  "w": 3400, "h": 2400,
  "spawns":   [{ "x": 600, "y": 260 }],                       // 出生点，可多个
  "obstacles":[{ "x": 0, "y": 0, "w": 3400, "h": 140 }],      // 矩形墙体
  "crates":   [{ "x": 520, "y": 685, "t": "safe" }],          // t 省略 = 每局按权重随机
  "extracts": [{ "x": 2130, "y": 650, "name": "A" }],         // 至少一个
  "nests":    [{ "x": 1090, "y": 800 }],                      // 敌人据点
  "units":    [{ "x": 700, "y": 685, "type": "runner" }]      // 兵种布点
}
```

`type` 取值：`runner` / `shooter` / `brute` / `sniper` / `rocket` / `flamer` / `boss`。
导入时会自动夹紧越界坐标、把压墙的物件挪开，并给出警告而不是直接拒绝。

## 技术说明

- **渲染**：Canvas 2D，程序化绘制全部美术，没有任何图片资源。
- **音效**：WebAudio 实时合成（枪声、翻箱、脚步、撤离提示等），不加载音频文件。
- **架构**：单文件内按段落划分 —— 配置数据（武器 / 配件 / 容器 / 敌人 / 收集品）→ 输入 → 玩家与敌人 AI → 子弹与粒子 → 战利品与结算 → UI 面板。
- **存档**：`localStorage`

  | 键 | 内容 |
  | --- | --- |
  | `neonpurge_extract_v1` | 主存档：资金、已购武器、配件库、每把枪的装配、仓库收集品、统计 |
  | `neonpurge_map_v1` | 自定义地图（编辑器写入） |

  大厅右下角有「重置存档」，注意这会清空全部进度。

## 数值说明 / 已知取舍

- **移速**：玩家 220，小兵追击 168（约 1.3 倍）—— 能拉开，但不再是想绕就绕。开镜移速按枪重分级（R93 97 / SR9 121 / M870 136 / M4A1 136 / 野牛 141 / 93R 172 / G17 176 / G18 189），最重的狙击枪开镜仍慢于小兵，需要架枪位置而不是边跑边打。
- **方向权重**：敌人 AI 的方向系数（盾兵侧移 0.7、机枪兵 0.5、狙击兵 0.38 等）会真实生效，不再被向量归一化抹平。
- **战斗节奏**：普通图小兵 34 血，M4A1 两发即倒，遭遇战以「抢先手」为主；机密图拉到 68 血，才有对枪过程。
- **增援**：普通图首波 90 秒、间隔递减到 30 秒；机密图首波 60 秒、间隔递减到 28 秒。增援只提升生命值（每波 +16%），不提升移速与反应。
- **经济**：收集品要先撤离变现，阵亡则全部丢失 —— 机密图的收益更高，但要先扛住 2 倍血量的守军。
